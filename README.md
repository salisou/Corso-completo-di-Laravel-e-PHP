# Corso completo di PHP e Laravel

Percorso didattico dedicato allo sviluppo backend con PHP e Laravel.

## Percorso
- Fondamenti di PHP
- Variabili, tipi e operatori
- Condizioni e cicli
- Funzioni e array
- Form e validazione
- Programmazione a oggetti
- Composer
- Laravel
- Routing e Controller
- Blade
- Eloquent
- Migrazioni e database
- Autenticazione
- CRUD
- API

**Stato:** repository didattico da completare progressivamente con lezioni, esercizi e progetto finale. Il materiale esistente viene conservato.
